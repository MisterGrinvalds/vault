# AI Configuration

This directory contains configuration files, prompts, and settings for AI tools and assistants.

## Structure

- **claude/** - Claude AI specific configuration
  - **agents/** - Custom agent definitions and configurations
  - **commands/** - Saved Claude commands and workflows
- **prompts/** - Reusable prompts and prompt templates

## Usage

Store your AI-related configuration files here to:
- Version control your custom AI agents
- Share prompts and commands across projects
- Keep AI configurations organized and accessible
- Backup important AI workflows

## Examples

- Custom agent definitions (JSON or YAML)
- Prompt templates for specific tasks
- Claude command configurations
- AI workflow documentation

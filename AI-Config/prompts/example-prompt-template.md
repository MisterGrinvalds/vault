# Example Prompt Template

A reusable prompt template for consistent AI interactions.

## Template

```
Role: {role_description}

Task: {task_description}

Context: {background_information}

Requirements:
- Requirement 1
- Requirement 2
- Requirement 3

Output Format: {desired_format}

Additional Instructions:
{any_special_instructions}
```

## Variables

- **{role_description}** - The role you want the AI to assume
- **{task_description}** - Clear description of what you want done
- **{background_information}** - Relevant context
- **{desired_format}** - How you want the output formatted
- **{any_special_instructions}** - Any special considerations

## Example Usage

```
Role: You are a technical documentation writer with expertise in API documentation.

Task: Create comprehensive API documentation for a REST endpoint.

Context: We have a new user authentication endpoint that needs to be documented.

Requirements:
- Include endpoint URL and HTTP method
- Document all request parameters
- Show example requests and responses
- Include error codes and their meanings

Output Format: Markdown with code blocks

Additional Instructions:
Use clear, concise language suitable for developers of all skill levels.
```

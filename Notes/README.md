# Notes

This directory contains Obsidian vaults and general note-taking content.

## Structure

You can organize your Obsidian vaults here in subdirectories. Each vault can be a separate Obsidian workspace.

## Example Organization

```
Notes/
├── Personal/          # Personal notes and journals
├── Projects/          # Project-related notes
├── Learning/          # Learning materials and study notes
└── Archive/           # Archived or completed notes
```

## Getting Started with Obsidian

1. Open Obsidian
2. Click "Open folder as vault"
3. Select a subdirectory within this Notes folder
4. Start taking notes!
